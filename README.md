# 3 Estudos Interativos sobre o livro de Artista

## Sobre o projeto

Estas obras foram realizadas para a disciplina V204 - Laboratório IV, oferecida no instituto de Artes da Universidade Estadual de Campinas, no segundo semestre de 2026, com o nome, Impressões gráficas: considerações sobre o tempo e a memória na produção de livros de artista e livros-objetos, ministrada pela docente Luise Weiss com a professora Fabiana Grassano.
